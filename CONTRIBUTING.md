# Как помочь LANwatch

Если вы не разработчик и хотите только предложить свою модель, используйте
пошаговую инструкцию **[«Добавить свой роутер»](docs/ADD_ROUTER.md)**.

## Сообщить о неподдерживаемом роутере

Сформируйте минимальный диагностический файл:

```text
python -m lanwatch probe --router http://192.168.1.1
```

Перед публикацией обязательно откройте `lanwatch-probe.json` и проверьте его.
Команда не должна включать IP роутера, MAC/IP устройств, их имена, пароль,
токен, ответы API или локальные пути. Укажите в issue производителя, точную
модель и версию прошивки отдельно.

Создать заявку можно через готовую форму
**[«Поддержка нового роутера»](https://github.com/B1MAS/lanwatch/issues/new?template=router_support.yml)**.

Не прикладывайте экспорт событий, дамп трафика, резервную копию роутера или
полные ответы API: они могут содержать сведения о вашей сети.

## Добавить адаптер

1. Создайте ветку от актуальной основной ветки.
2. Используйте `docs/ADAPTER_TEMPLATE.py` и общий интерфейс адаптеров.
3. Ограничьте методы чтением и минимально необходимыми endpoint.
4. Добавьте тесты с полностью синтетическими ответами API.
5. Обновите `docs/COMPATIBILITY.md` и README.
6. Выполните `python -m unittest discover -s tests -v`.

В pull request опишите модель роутера, проверенную прошивку, доступные функции и
ограничения. Не включайте реальные учётные данные и сведения об устройствах.
