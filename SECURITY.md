# Безопасность

## Сообщить об уязвимости

Не публикуйте сведения об уязвимости, токены, пароли, MAC/IP-адреса или полные
ответы API роутера в открытом issue. Сначала откройте приватное сообщение через
GitHub Security Advisories в этом репозитории. Если функция недоступна, создайте
issue без технических деталей и попросите владельца указать закрытый канал.

В сообщении укажите версию LANwatch, операционную систему, способ установки,
минимальные шаги воспроизведения и ожидаемое влияние. Перед отправкой удалите
данные своей сети.

## Модель безопасности

- веб-панель допускает привязку только к `127.0.0.1`;
- пароли роутеров не сохраняются LANwatch на диск;
- сетевые данные по умолчанию не отправляются наружу;
- webhook и Telegram включаются пользователем явно;
- адаптеры предназначены для операций чтения;
- диагностический `probe` не собирает список устройств и ответы закрытых API.

LANwatch не является межсетевым экраном, антивирусом или полноценной SIEM. Он
показывает только изменения, которые можно определить по доступному API роутера
и локальному ARP-кэшу.
