# Проверка v0.5.1 на Xiaomi BE5000 / RD18

Тест проводится только на собственном роутере, с уже выданным доступом к его
локальной панели. LANwatch работает read-only и не меняет его конфигурацию.

1. Распакуйте v0.5.1 и запустите установщик для своей ОС.
2. Если данные v0.4.0 находятся в старом каталоге проекта, запускайте команды
   оттуда или укажите прежний каталог через `--data-dir`.
3. При желании обновите локальную таблицу производителей: `python -m lanwatch oui-update`.
4. Запустите аудит:

   ```text
   python -m lanwatch audit --adapter miwifi --router http://192.168.31.1
   ```

5. Проверьте, что Wi-Fi шифрование и гостевая сеть имеют осмысленное состояние.
   WPS, UPnP, проброс портов и остальные недоступные поля должны остаться
   `UNKNOWN`, если API их не отдал.
6. Запустите `python -m lanwatch check`, затем `python -m lanwatch web`. Сверьте устройства API,
   ARP-кэша и пересечения источников; записи только из ARP должны иметь
   «статус не подтверждён».
7. Убедитесь, что устройства с рандомизированным MAC не получают выдуманного
   производителя, а данные API показываются отдельно от записей ARP.

Для сообщения об ошибке приложите текст ошибки и модель/версию прошивки.
Не прикладывайте пароль панели, токен, SSID, Wi-Fi пароль или необработанный
дамп ответа API.
