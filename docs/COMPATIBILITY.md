# Совместимость адаптеров

Матрица показывает фактический объём проверки, а не обещание поддержки всей линейки.

| Адаптер / устройство | Статус | Наблюдение | Аудит Wi-Fi |
|---|---|---|---|
| Xiaomi BE5000 / RD18 (прошивка 1.0.60, тест пользователя) | Проверено пользователем; аудит v0.5 ожидает live-проверку | локальный vendor API: WAN, клиенты, системный статус; дополнительно кэш соседей ОС | основной Wi-Fi и гостевой режим, если endpoint доступен |
| Другие Xiaomi MiWiFi | Частично / зависит от прошивки | API неофициальный и может менять формат | неизвестно, пока не проверено на модели |
| OpenWrt через ubus | Экспериментальный | модель/права API и конкретная сборка требуют отдельной проверки | неизвестно в текущей версии |
| Другие роутеры | Не поддерживаются | требуется отдельный адаптер и безопасный probe-файл | неизвестно |

WPS, UPnP, проброс портов, удалённое администрирование, DHCP и администраторы намеренно не обозначаются безопасными: текущие адаптеры не сообщают эти значения подтверждённым read-only способом.

## Данные для нового адаптера

Создайте issue с безопасным файлом `lanwatch probe --output router-probe.json`. Проверьте JSON вручную перед публикацией. Не присылайте пароль, token, cookies, SSID, Wi-Fi пароль, публичный IP или полный дамп API. Реальные MAC/IP из issue не нужны; тесты должны использовать синтетические фикстуры из документации.
